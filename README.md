# 🌙 LuxeBETS

> Strategy > Luck  
> Every pick matters.

LuxeBETS is a **6-day competitive sports tournament app** where players earn points through daily picks and compete on a live leaderboard for real prizes.

---

## 🧠 The Concept

This is NOT elimination.

You don’t get knocked out — you **compete through points**.

- 📅 6-day tournaments (Tuesday → Sunday)
- 🎯 Make picks every day
- 📈 Earn points for correct selections
- 🏆 Top players win based on total points

---

## 🔥 Core Features

### 🏟 Tournament System
- Weekly tournaments
- Join window: **Sunday → Tuesday**
- Play window: **Tuesday → Sunday (6 days)**
- Entry tiers: **$20 / $50 / $100**

---

### 🎮 Picks System
- Make picks daily across available games
- Picks are **locked once submitted**
- Points awarded based on correctness + strategy
- Supports multiple pick types (ex: Moneyline)

---

### 📊 Point System

- Earn points for correct picks
- Goal: **20 total points**

| Points Earned | Reward |
|--------------|--------|
| 20+ points   | 🥇 100% of prize pool |
| 10–19 points | 🥈 50% of prize pool |
| <10 points   | 🥉 25% of prize pool |

- If players tie → prize is split evenly

---

### 🏆 Leaderboards
- Live rankings based on total points
- Updated after games are graded
- Compete against all participants in the tournament

---

### 💰 Wallet System
- Deposit & withdraw funds
- Track:
  - Balance
  - Deposits
  - Winnings
  - Spending
- Secure transaction handling

---

### 🎟 Referral Codes
- Optional code when joining tournaments
- Used for promotions, bonuses, or free entries

## 🧩 How It Works

1. Join a tournament 💰  
2. Make daily picks 🎯  
3. Earn points based on accuracy 📈  
4. Climb the leaderboard 🏆  
5. Win based on total points 💸  

---

## ❓ How Picks Work (Reworded & Clean)

- Each day, players choose from available games
- You can select a team (ex: Moneyline pick)
- Once submitted, picks are locked for that day
- After the game finishes:
  - Correct pick → points awarded
  - Incorrect pick → no points
- Points accumulate across all 6 days

💡 Strategy matters — it’s not just about winning picks, but **when and how you make them**
